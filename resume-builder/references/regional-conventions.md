# Country & Region Conventions

Apply the conventions of the country where the job is, not where the person lives. If the employer is a US multinational hiring locally (e.g., Google Dublin), local conventions still apply for personal details, but a tighter US-style document is welcome. When a convention is legally sensitive (photos, age, marital status), default to *omitting* personal data unless the local norm clearly expects it — omission rarely hurts; inclusion can invite bias.

Conventions shift over time and vary by industry; treat these as defaults and tell the person what you applied.

## Ireland — detail (common tech-hub request)
- Title it nothing (just the name) or "Curriculum Vitae"; file name `Firstname_Lastname_CV.pdf`.
- 2 pages normal for experienced; 1 for graduates. Personal profile (summary) of 3–4 lines at the top is expected.
- Non-EEA candidates: state status clearly near the top because sponsorship is an early filter for many employers: e.g., "Stamp 4 (no sponsorship required)", "Stamp 1G", "Critical Skills Employment Permit holder", "Irish citizen". Only include what the person confirms.
- Irish/UK spelling (optimise, organise, programme for non-software programmes, centre).
- Phone in +353 format; location "Dublin, Ireland".
- Interests section optional; if used, 1 line, genuine.
- References: "Available on request" not needed.

## UK — detail
- No photo, DOB, marital status, NI number. "Right to work in the UK" line helpful when not obvious (e.g., foreign education/experience).
- 2 pages A4. Degree classification (First, 2:1) included for recent grads.
- A-levels only for graduates/early career.

## US — detail
- Letter size; 1 page under ~10 years (r/EngineeringResumes is strict on this), 2 pages for senior with substance.
- No photo, age, DOB, marital status, nationality, religion, SSN. Graduation year optional for experienced candidates.
- City, State (e.g., "Seattle, WA"); "Open to relocation" if relevant.
- GPA if ≥3.5 and recent. No references section.

## Germany — detail
- Tabular Lebenslauf tradition (dates in left margin) — but for ATS, keep single-column text with dates on the role line instead of an actual table.
- Month/year precision (MM/YYYY). Explain gaps briefly.
- Language skills with CEFR levels (German B2, English C1/C2) — important.
- Photo: optional; if the person wants one, warn about ATS parsing and keep it a small inline image at the top only in the PDF version.
- Signature/date line traditional, optional now.

## India — detail
- MNC/product companies: write like a global resume (no photo, no DOB, no father's name, no declaration).
- Show company tier/scale where helpful; tech stack heavy Skills section is expected.
- CGPA/percentage common for freshers; for experienced, degree + college + year.
- Naukri/LinkedIn/portal parsing: .docx and text PDF both fine.

## Language versions (Spanish, Portuguese, German, French…)
- Write the target-language version natively; don't translate line by line. Same structure, same facts, natural phrasing.
- Keep industry-standard technical terms in English: backend, frontend, DevOps, microservices, CI/CD, SOLID, CQRS, Kubernetes.
- Spanish action verbs in first-person preterite without the pronoun: Desarrollé, Diseñé, Implementé, Lideré, Optimicé, Automaticé, Migré, Reduje, Construí, Integré (keep the accents).
- Translate section headings: Experiencia, Habilidades / Competencias técnicas, Educación / Formación, Proyectos, Certificaciones (Spanish); Berufserfahrung, Kenntnisse, Ausbildung, Projekte (German).
- Date month names in the target language (ene/feb/mar…, Jan/Feb/Mär…), "Actualidad"/"Presente" or "heute" for current roles.
- List languages with CEFR levels (C1, B2) — expected across Europe and LATAM.

## Conversion checklist (when moving a resume between regions)
1. Rename resume ↔ CV and adjust file name.
2. Adjust length (US 1 page ↔ UK/IE 2 pages).
3. Add/remove photo, DOB, nationality per table.
4. Add/remove work authorization line.
5. Switch spelling (US ↔ UK English) and date format (US: Jan 2024; EU: 01/2024 or Jan 2024 — both fine; avoid 01/02/2024 ambiguous day/month).
6. Paper size (Letter for US/Canada; A4 elsewhere) — `build_resume.py --paper letter|a4`.
7. Phone with correct country code; location format.
8. Summary vs no summary (US new grad: none; UK/IE/AU: personal profile customary).
9. Grade systems: GPA ↔ classification ↔ CGPA — keep the original and add an equivalence only if it helps ("First Class Honours (GPA equivalent ~3.8)" is optional and should be avoided unless a credential evaluation exists).
